24 October 2026. Reviewed the supplied clicking, scrolling, themes and capability
audit against the active browser code, including later overrides. The supplied
document was evidence to verify; its proposed access-control changes were not
applied without checking their effect on private account data.

## Draft and privacy boundaries

- Drafts are held in memory for this session. Apply/Save before reloading; they are
  not durable backups and do not silently change geometry, reports or server data.
- Saved/applied model values remain the source for calculations and exports.
- Drafts never include passwords, login forms, payment fields or account settings.
- Changing projects cannot show another project's draft. A new server/profile
  load receives new project objects rather than reusing another account's draft.
- Static preview library access remains device-local and is not an authentication
  boundary. Account backend project APIs remain authenticated.
- No backend provider, hosting audience, paid entitlement or billing activation
  was changed by these UI fixes. Existing Free modelling tools remain Free.

## Main files

- `dist/app.js`: fractional fields, component quantity constraint, download status,
  empty BOM and quick-add binding.
- `dist/studio-ui.js` / `dist/advanced.js`: retained command actions, dynamic import
  dispatch, public-template creation prompt.
- `dist/server-mode.js`: public resources, internal login continuation and truthful
  guest status. Private route guards remain.
- `dist/workspace-drafts.js`: session draft isolation, current-adapter commands and
  keyboard sketch deletion. Loaded after the server adapter.
- `dist/workbench.css` / `dist/studio-3d.js`: adaptive height, wheel routing, help,
  inspector stacking.
- `dist/color-system.css`: circuit colors, thin tabs, sticky tables and notices.
